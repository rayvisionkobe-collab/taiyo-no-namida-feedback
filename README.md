# 太陽の涙、虚脱の空 – フィードバック

プロトタイプへの、バグ報告・感想・改善の提案は、ここにお願いします。

メインのコードは、別の Private リポジトリで管理しています。
ここは、**フィードバック専用の Public リポジトリ**です。コードは置きません。

## 送り方

- **バグ** → Issues → [バグ報告] を選ぶ
- **感想・ひとこと** → Issues → [感想] を選ぶ (短くてOK)
- **こうしてほしい** → Issues → [改善の提案] を選ぶ

GitHub アカウントがない方は、アプリのフッターにある **Googleフォーム (匿名OK)** からどうぞ。

## ルール

- 個人情報 (名前・住所・連絡先) は、書かないでください
- スクショは、顔・車のナンバーが写っていないものにしてください
- 対応は、できる範囲で、順番にやります。すぐ返せないこともあります

## 開発中だと分かる表示

アプリの右上に `[ PROTOTYPE – 開発中 ]` があります。公開後は `[ β版 ]` になります。
